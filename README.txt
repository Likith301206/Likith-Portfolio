# Likith S Portfolio

Single-page portfolio built in HTML, CSS and JavaScript.

## Included
- Flat black single-page layout
- Live clock
- Profile photo supplied by Likith
- SkillForge AI project image
- Smart Shield project image
- Bus Reservation System project image
- Four supplied certificate PDFs with real preview images
- GitHub / LinkedIn / X / Instagram links
- Education section
- Resume section placeholder

## Resume
A resume PDF was not included in the uploaded files used for this build, so the resume buttons are intentionally not linked to a missing file. Add the PDF as:

resume/Likith_S_Resume.pdf

Then the View/Download buttons can be enabled.

## Run
Open `index.html` with VS Code Live Server.
